# Chiro Halle website

Nieuwe statische website voor [chirohalle.be](https://chirohalle.be). Geen build-stap nodig: open `index.html` of zet de map op eender welke webhost.

```
index.html
assets/css/style.css
assets/js/main.js
assets/img/groepsfoto.webp
```
